# IoT Automatic Pet Feeder System (ระบบให้อาหารสัตว์เลี้ยงอัตโนมัติ)
Automatic pet feeder system using ESP8266, Blynk IoT, and RFID

โครงงานพัฒนาเครื่องให้อาหารสัตว์เลี้ยงอัจฉริยะ ควบคุมและตรวจสถานะจากระยะไกลผ่านเครือข่ายอินเทอร์เน็ต (IoT) ซึ่งเป็นส่วนหนึ่งของรายวิชา Basic Internet of Things มหาวิทยาลัยนเรศวร

## 📌 วัตถุประสงค์และฟังก์ชันการทำงาน
* **Scheduled Feeding:** ตั้งเวลาให้อาหารอัตโนมัติได้ 2 รอบต่อวัน (เช้า/เย็น) ซิงค์เวลาผ่าน RTC Widget
* **Manual Feeding:** สั่งให้อาหารทันทีผ่านปุ่มบนแอปพลิเคชัน Blynk
* **Physical Feeding (RFID):** สั่งให้อาหารหน้าเครื่องด้วยการแตะบัตร RFID (MFRC522) ที่ได้รับอนุญาต
* **Food Level Alert:** แจ้งเตือนผ่านแอปพลิเคชันทันทีเมื่ออาหารใกล้หมดถังด้วย IR Sensor
* **Safety Limit:** มีระบบจำกัดจำนวนครั้งการให้อาหารสูงสุดต่อวันเพื่อความปลอดภัยของสัตว์เลี้ยง

## 🛠️ อุปกรณ์ที่ใช้ในโครงงาน (Hardware & Software)
1. **ESP8266 (NodeMCU):** ไมโครคอนโทรลเลอร์หลักเชื่อมต่อ Wi-Fi
2. **Micro Servo Motor SG 180:** ควบคุมการเปิด-ปิดช่องปล่อยอาหาร (มุม 0° และ 140°)
3. **RFID Module (MFRC522):** โมดูลอ่านบัตรความถี่ 13.56 MHz
4. **IR Sensor:** ตรวจจับระดับอาหาร
5. **Blynk IoT Platform:** แอปพลิเคชันบนสมาร์ตโฟนและ Cloud Server

## 🔌 การต่อสายวงจร (Wiring Diagram)
| ESP8266 Pin | เชื่อมต่อกับอุปกรณ์ | หน้าที่ |
| :--- | :--- | :--- |
| **D1** | IR Sensor (OUT) | รับสัญญาณดิจิทัลตรวจสอบอาหาร |
| **D4** | Servo Motor (Signal) | ส่งสัญญาณ PWM ควบคุมการเปิด-ปิด |
| **D8 / D3 / D5 / D6 / D7** | MFRC522 (SPI Bus) | ขาสำหรับสื่อสารกับโมดูล RFID |
| **3.3V / VIN(5V) / GND** | ระบบจ่ายไฟ | จ่ายไฟให้อุปกรณ์และใช้กราวด์ร่วมกัน |
